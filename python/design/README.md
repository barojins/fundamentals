# Data Structure Design Practice Suite

This directory contains complete, runnable, and typed Python practice implementations
for **134 LeetCode Data Structure Design** problems.

## How to Practice
1. Open any problem file, e.g. [`0146_lru_cache.py`](0146_lru_cache.py).
2. Review the problem description, constraints, and design invariants in the docstring.
3. Clear or modify the class method implementations to practice active recall.
4. Run the file directly to verify your solution against the built-in test suite:
   ```bash
   python python/design/0146_lru_cache.py
   ```
